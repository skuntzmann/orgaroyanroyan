Installer l'application

Installez ORGANISATION ROYAN-ORGUES directement sur votre écran d'accueil.

Si le bouton d'installation n'apparaît pas :

ouvrez le menu ⋮ de Google Chrome, puis choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».
Installer sur iPhone / iPad

Ouvrez cette page avec Safari.

Appuyez sur le bouton Partager puis choisissez « Sur l'écran d'accueil ».

Installer l'application

Si votre navigateur propose l'installation de cette application, utilisez l'icône d'installation présente dans la barre d'adresse.

Vous pouvez également ouvrir le menu de votre navigateur et rechercher « Installer l'application ».
